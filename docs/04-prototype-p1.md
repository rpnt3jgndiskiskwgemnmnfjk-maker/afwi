## 1. 実装した範囲

| 区分 | 内容 |
|---|---|
| 地図 | 射程を示す地図（17 エリア、500km ごとの射程リング、届く目標の強調）、拡大表示 |
| マップ外ボックス | 青 3（後方グアム・本土後方・スタンドオフ）、赤 2（内陸後方・スタンドオフ）。部隊数と残り弾数を表示 |
| シナリオ | S0「南西防空」3 作戦日、開始段階 3、要域は東シナ海と台湾東方海域 |
| 遊び方 | 2 人（交代時に目隠し画面）／1 人で両軍（ルール確認用） |
| 任務 | 制空、打撃（狙い：滑走路／駐機中の部隊）、スタンドオフ打撃、早期警戒、給油、転地 |
| 判定 | d4 ダイスプール。修正の内訳と命中率・期待命中数を計画時に表示し、解決後は出目を表示 |
| 基地と ACE | 滑走路 0〜3 と出撃上限、駐機／分散、修復（兵站 2） |
| 集計 | 兵站、国民の意志、エスカレーション、勝利点、戦後評価（乱数シードを表示） |
| 保存 | 自動保存（localStorage）。タイトル画面の「続きから」で再開 |

## 2. P1 で簡略化した点（P2 で見直す）

- 戦場の霧（探知判定）は未実装。敵部隊の位置と数は常に見える。相手の計画だけを隠す。
- 国力カード、イベント、増援は未実装。
- 打撃任務の部隊は空対空射撃をしない（護衛は制空任務の部隊が担う）。
- 地上配備防空（SAM）は、基地への打撃や駐機狙いの命中の対象にしない。
- 防空制圧（SEAD）は未実装。目標の基地に防空があれば打撃は常に基準 +1。
- 給油機は目標エリアの上空にいるものとして扱い、そのエリアの航空戦で支援機として狙われる。
- CPU（対コンピュータ戦）は P2。
- 数値は暫定。自動対戦によるバランス調整は P4。

## 3. 構成

```
src/engine/   ルールエンジン（純 TypeScript。UI に依存しない）
  types.ts    型定義
  rng.ts      シード付き乱数（xoshiro128**）と d4
  geo.ts      地点と射程帯の表引き
  orders.ts   任務の選択肢、目標候補、費用、計画の検証
  combat.ts   d4 の命中判定と確率分布
  resolve.ts  1 ターンの同時解決と勝敗判定
src/data/     地図（map.json）、部隊の能力値、シナリオ
src/ui/       画面（Preact + SVG）
tests/        エンジンの単体テスト（Vitest）、通しプレイ（Playwright）
tools/        地図データの生成、アーティファクト用 HTML の生成
```

## 4. 開発の手順

| 目的 | コマンド |
|---|---|
| 開発サーバー | `npm run dev` |
| 型チェック | `npm run typecheck` |
| 単体テスト | `npm test` |
| 単一 HTML のビルド | `npm run build`（`dist/index.html`） |
| アーティファクト用 | `npm run build:artifact`（`dist/artifact.html`） |
| 通しプレイ確認 | `npm run build && node tests/e2e/play.mjs` |
| 地図データの再生成 | `npm run mapgen` |

## 5. 確認結果（2026-10-31）

- 単体テスト 16 件が成功。決定性（同じシード・同じ計画で同じ結果）、d4 の偏りのなさ、射程帯、計画の検証、分散の効果、エスカレーション段階 5 での終了、ランダムな計画による 300 局の完走を確認。
- 通しプレイ（1 人で両軍、3 作戦日）が最後まで進み、ページのエラーなし。
- 画面幅 1280px とスマホ横持ち（844×390）で表示を確認。

## 6. 既知の注意点

- `vitest` 3.2.7 には開発時のみ影響する既知の脆弱性（モック機能）が報告されています。修正版は vitest 5 系で、vite の更新を伴うため P3 の構成見直しで対応します。配布物（APK・HTML）には含まれません。
- フォントは Google Fonts から読み込んでいます。オフラインの APK では P3 でフォントを同梱します。
