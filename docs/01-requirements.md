### 0.2 方針

- 原作のルール、マップ、カード文言、図版、名称は**複製しない**。
- 「航空中心・作戦級・多領域」という同じ**ジャンルのオリジナル作品**として、ゼロから設計する。
- 理由:
  1. 原作の権利関係と配布条件は**未確認**（CAC限定の配布、市販版の存在）。
  2. 既存作品の再現は、改名しても権利侵害のリスクが残る。
  3. オリジナルにしておけば、将来の配布範囲（部外配布やストア公開）の制約が少ない。
- 原作の公開情報で言及されている要素（d4ダイス、射程帯マップ、マップ外ボックスなど）は**意図的に採用しない**。

## 1. 目的

航空作戦の基本概念（航空優勢、出撃生成、ACE＝分散運用、多領域支援、国力の諸手段、エスカレーション管理）を、**Android スマートフォン1台で 30〜60 分**で体験できる作戦級ウォーゲームを作る。

## 2. 想定利用者と利用シーン

| 区分 | 内容 |
|---|---|
| 主な利用者 | 安全保障・航空作戦に関心のある個人、ウォーゲーム愛好者、自習目的の学習者 |
| 利用シーン1 | ソロプレイ（対CPU）、通勤時間などに1シナリオを30〜60分 |
| 利用シーン2 | ホットシート（1台を2人で交互に使用）で対戦・研究会 |
| 利用シーン3 | チュートリアルで概念を学習（確率と判定根拠を画面に表示） |

## 3. スコープ

| 区分 | 含む | 含まない（将来検討） |
|---|---|---|
| MVP（v1.0） | ソロ対CPU、ホットシート、シナリオ3本、日本語UI、オフライン完結、APK配布 | オンライン対戦、シナリオエディタ、Google Play公開、iOS |
| 将来 | 英語UI、シナリオ追加、AI強化（MCTS）、リプレイ共有 | 実在部隊・実在基地名の詳細再現 |

## 4. 機能要件

| ID | 機能 | 内容 | 優先度 |
|---|---|---|---|
| FR-01 | シナリオ選択 | チュートリアル・標準・上級の3シナリオから選ぶ | 必須 |
| FR-02 | 陣営・モード選択 | 青／赤、対CPU（難易度3段階）／ホットシート | 必須 |
| FR-03 | 作戦地図 | 18エリアのノード地図。ピンチズーム、パン、タップで選択 | 必須 |
| FR-04 | 基地とACE | 部隊の拠点（ハブ／スポーク）と分散配置の切替 | 必須 |
| FR-05 | 任務割当（航空任務計画） | 部隊を任務（制空・打撃・SEAD・偵察・給油・輸送）に割り当て、パッケージを編成 | 必須 |
| FR-06 | 同時解決 | 双方の計画を同時に解決し、戦闘結果をアニメーションとログで示す | 必須 |
| FR-07 | 戦場の霧 | 探知されていない敵部隊は「？」と数の目安だけを表示 | 必須 |
| FR-08 | 国力カード | 外交・情報・経済・宇宙／サイバー支援のカードを毎ターン1枚使用 | 必須 |
| FR-09 | 意志とエスカレーション | 国民の意志トラック（0〜10）とエスカレーション段階（0〜5）を管理 | 必須 |
| FR-10 | 勝敗判定と戦後評価 | 勝利点で判定し、戦後評価（損耗・出撃数・転換点）を表示 | 必須 |
| FR-11 | CPU対戦 | ユーティリティ評価型AI。易・中・難の3段階 | 必須 |
| FR-12 | ホットシート秘匿 | 手番交代時に目隠し画面を出して計画を見せない | 必須 |
| FR-13 | セーブ／ロード | 自動保存と手動3スロット。アプリ終了後も再開できる | 必須 |
| FR-14 | ルール参照 | ゲーム内ルールブック、用語集、判定確率の表示 | 必須 |
| FR-15 | 設定 | 文字サイズ、効果音、アニメ速度、色覚配慮モード | 推奨 |
| FR-16 | 再現性 | 乱数シードを表示し、同じシード・同じ計画なら同じ結果になる | 推奨 |
| FR-17 | 判定の説明 | 交戦ごとに命中率と修正要因を内訳で示す（学習用途） | 推奨 |

## 5. 非機能要件

| ID | 区分 | 要件 |
|---|---|---|
| NFR-01 | 対応OS | Android 8.0（API 26）以上を目標。最終値は採用する Capacitor 8 の最低要件（**未確認**）と照合して確定 |
| NFR-02 | 画面 | スマホ横持ちを主とし、縦持ちとタブレットにも対応 |
| NFR-03 | ネットワーク | オフラインで完結。INTERNET 権限を要求しない |
| NFR-04 | 性能 | コールドスタート3秒以内、地図操作60fps、CPU思考は中級端末で1ターン2秒以内 |
| NFR-05 | 容量 | APK 20MB以下 |
| NFR-06 | 信頼性 | ルール処理は純関数で書き、乱数はシード付き。セーブデータに版番号を持たせて移行できるようにする |
| NFR-07 | 品質 | ルールエンジンの単体テストのカバレッジ80%以上。CPU同士の自動対戦1,000局でクラッシュ0件 |
| NFR-08 | アクセシビリティ | 陣営は色と形で区別する。最小タップ領域48dp。文字サイズ3段階 |
| NFR-09 | 言語 | 日本語を先行。文字列は外部化して英語を追加できる構造にする |
| NFR-10 | 保守性 | アーティファクト試作版とAPK版で同じソースコードを使う |

## 6. 制約・前提

- 公開情報だけを使う。部内限定資料や CAC 限定資料には依拠しない。
- 装備の性能は抽象化した 1〜10 の値で表し、実在の数値を再現しない。
- 実在組織の公式ロゴ、部隊章、国旗を使わない。陣営は「青軍」「赤軍」と表記する（未決事項 D-01）。
- 配布はAPKを直接渡す方式（サイドロード）。署名鍵は利用者が保管する。

| D-03 | MVPのプレイモード | 対CPU＋ホットシート |

| D-05 | 想定端末 | スマホ横持ち |
| D-06 | 配布範囲 | 個人・知人へのAPK直接配布 |
