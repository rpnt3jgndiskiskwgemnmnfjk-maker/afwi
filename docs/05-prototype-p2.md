## 1. P1 から追加したもの

| 区分 | 内容 |
|---|---|
| シナリオ | S1「第一列島線」（8 作戦日）、S2「海峡危機」（12 作戦日）。増援の到着予定つき |
| 遊び方 | CPU と対戦（陣営と強さ「易しい／標準」を選ぶ）、2 人で対戦、1 人で両軍 |
| 戦場の霧 | 毎朝の情報フェイズで、敵部隊のいる地点ごとに d4 で探知（3+）。未探知の地点は「?」と数の目安だけ表示 |
| 国力カード | 8 種 12 枚の山札。手札 3 枚まで、1 日 1 枚使える |
| 情勢 | 2 日目以降の朝に 1 枚。悪天候・同盟国の支援・国内の結束・部品不足・停戦交渉の打診・平穏 |
| 任務 | 防空制圧（SEAD）、偵察（RECON）、輸送（AIRLIFT）を追加 |
| 意志 | 後方ボックスが攻撃されると −1、要域の航空優勢を 3 日続けると +1 |
| 中立基地 | ルソン北部は「基地使用の合意」を先に使った陣営が使える |
| CPU | 易：手作業のルール。標準：候補 6 案を相手の想定計画に対して 3 回ずつ試しに解決し、評価関数で選ぶ |

ルールの変更点は `docs/02-game-design.md` の「第0.3版の変更点」にまとめています。

## 2. CPU と調整の確認結果（2026-10-31）

CPU 同士の対戦（各 40〜60 局、乱数シードを変えて）で確認しました。

| 確認 | 結果 |
|---|---|
| 標準と易しいの比較 | すべてのシナリオ・両陣営で、標準の勝率は易しい以上（S1 の青側のみ同程度） |
| S0（標準同士、60 局） | 青 28・赤 25・引き分け 7（調整前） |
| S1（標準同士、40 局） | 青 23・赤 14・引き分け 3（調整後。調整前は赤が 7 割以上） |
| S2（標準同士、40 局） | 青 17・赤 19・引き分け 4（調整後。調整前は赤が 9 割以上） |
| 思考時間 | 標準 CPU の 1 日分の計画は約 15 ミリ秒（要件 NFR-04 の 2 秒以内） |

本格的なバランス調整（陣営別勝率 40〜60%、自動対戦 1,000 局）は P4 で行います。

## 3. 既知の制約（P3 以降で対応）

- 標準 CPU の先読みは真の状態（相手の未探知の部隊を含む）を使っています。P4 で戦場の霧を考えた推定に置き換えます。
- 国力カードで段階が下がっても、その日の計画はそのまま実行されます（計画時点の段階で検証）。
- 「難しい」CPU は P4 です。
- 開発用ツールの注意点（vitest の脆弱性、フォントの同梱）は `docs/04-prototype-p1.md` の 6 章のとおりです。
